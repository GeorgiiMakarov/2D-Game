CRYSTAL DEPTHS FX — как запустить у себя
========================================

ВАРИАНТ 1. Просто поиграть (без Node.js)
----------------------------------------
Внутри есть готовая сборка в папке dist/.
Открывать dist/index.html двойным кликом НЕЛЬЗЯ (браузер блокирует ES-модули с file://),
нужен любой локальный сервер:

  python3 -m http.server 8000 --directory dist
  затем открыть http://localhost:8000

или, если есть Node.js:

  npx serve dist


ВАРИАНТ 2. Разработка (Node.js 18+)
-----------------------------------
  npm install
  npm run dev        -> http://localhost:5173
  npm run build      -> пересобрать dist/
  npm run preview    -> посмотреть собранную версию

Если dev-сервер отдаётся наружу через https-прокси (ngrok, Codespaces, облачная
песочница) и HMR не подключается — запускай так: HMR_PUBLIC=1 npm run dev
Локально это не нужно.

Пересобрать спрайты из сырых картинок (нужны Python, Pillow, numpy):
  python3 tools/prep_assets.py


УПРАВЛЕНИЕ
----------
A / D или стрелки  — ходьба
Space / W          — прыжок, двойной прыжок, прыжок от стены по слизи
X                  — кирка
S                  — бросок слизи
Esc                — пауза
F2                 — настройки физики (можно отключать каждую симуляцию)
F3                 — метрики: FPS, мс на симуляции, размеры сеток, частицы

Если тормозит: F2 -> КАЧЕСТВО -> НИЗКОЕ, либо выключить «Навье–Стокс» и «Диффузионный свет».

Подробности про физику — в README.md.
